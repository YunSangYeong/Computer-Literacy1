# 문항 출처와 검토 범위

2026-10-20 작성. **원문 기출 0, 복원 0, 자체 제작 1,000**이다. 제3자의 기출 문제·정답·이미지를 복제하지 않았다. 연도·회차는 전부 null이다.

| 과목 | 개념형 | 계산·추론 유형 | 조건 변형 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 컴퓨터 일반 | 14 | 8 | 320 | 334 |
| 스프레드시트 일반 | 13 | 8 | 320 | 333 |
| 데이터베이스 일반 | 13 | 8 | 320 | 333 |
| 합계 | 40 | 24 | 960 | 1,000 |

64개 독립 유형(개념 40, 계산·추론 24)에 조건을 달리한 문제들이다. 1,000개의 서로 다른 출제 개념이나 기출 1,000개를 뜻하지 않는다. 은행이 계산 중심이므로 실제 시험의 전체 출제 범위·유형·난이도 분포를 재현한다고 주장하지 않는다. 시험 추출은 과목별 20개이며 각 개념/숫자 family에서 먼저 하나를 추출한다. 현재 과목별 유형 수가 20개 이상이므로 기본 시험은 같은 family를 중복 출제하지 않는다. 로컬 수입 은행에서 유형이 부족하면 남은 고유 ID로 채운다.

## 작성과 검증

- `scripts/generate_bank.py`에 모든 자체 작성 원고와 결정적인 조건 생성 규칙을 공개한다. 난수는 쓰지 않는다. ID와 순서는 고정한다.
- 작성 근거는 AI 일반 지식과 명시된 산술·논리·SQL 연산이다. 읽지 않은 교재·Microsoft 공식 문서·공식 기출을 읽었다고 인용하지 않는다.
- `sourceUrl`의 이 문서 주소는 작성 이력이다. 외부 정답 증빙이나 공식기관의 검증 표시가 아니다.
- 개념 40문항의 문제·네 보기·정답·해설은 내부 문장 검토했다. 답안이 유일하도록 일반적인 조건과 예외를 설명했다. 외부 독립 전문가 검수는 없다.
- 컴퓨터 320개·스프레드시트 320개는 생성 Python 코드와 분리된 TypeScript 계산으로 640개 정답을 재계산한다. 이는 실제 Excel/Access 실행 검증과 다르다.
- 데이터베이스 320개는 생성식을 호출하지 않고 메모리 SQLite 테이블에 명시된 값을 삽입하여 SQL을 실행한다. SQL은 Access와 공통인 기본 집계/비교/부질의만 사용하되 Access 제품 자체에서 실행한 것은 아니다.
- 보기 중복·정답 인덱스·고유 ID·본문/정렬한 보기의 지문·단위·원문 기출 메타데이터 미생성·재생성 바이트 일치 여부를 검사한다. 숫자형 오답은 정답과 다른 수치이다.
- 가족 내 의미 반복은 의도된 조건 변형이다. 가족 간 개념형/계산형 주제 중복도 가능하며 의미 중복을 완전히 제거했다고 주장하지 않는다.
- `reviewed`는 위 내부 검토·재계산 범위이다. 외부 전문가·공식 출제기준 대조 완료가 아니다. 수입 문항은 항상 `pending`으로 등록하여 실제 학습에서 제외한다.
